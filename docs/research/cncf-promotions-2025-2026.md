# CNCF maturity promotions in 2025 and 2026

Research date and cutoff: 2026-10-05.
Scope: Sandbox → Incubating and Incubating → Graduated promotions.
Status: checked against current official CNCF project records and announcements.

## Date and classification rules

Use the date on which CNCF records the maturity change. A press release can appear weeks or months later. The tables keep the event date and publication date separate. Project links lead to CNCF's dated project record; announcement links lead to the CNCF publication. Dates use ISO format.

New admission at Incubating is a separate event. It is not a Sandbox → Incubating promotion. CNCF also separates these events in its [project metrics](https://www.cncf.io/project-metrics/). Use the level names Sandbox, Incubating, and Graduated. These are project maturity levels, not software release states. The [TOC process](https://github.com/cncf/toc/blob/main/process/README.md) describes the requirements and review process.

## Slide selection

Include every confirmed promotion. Use four slides, one for each year and transition, to keep each list readable. Link each project name to its dated CNCF record. Label dates as maturity-change dates. Keep announcement dates and exclusions in these notes.

The workshop should explain the practical meaning of maturity: CNCF reviews adoption, governance, community, and security. Project graduation does not imply that every subproject, API, integration, or feature has the same stability. OpenTelemetry's [graduation announcement](https://www.cncf.io/announcements/2026/05/21/cloud-native-computing-foundation-announces-opentelemetrys-graduation-solidifying-status-as-the-de-facto-observability-standard/) explicitly describes Profiles as alpha. Check the specific component before adoption.

No tools were installed, no cluster resources were created, and no project code or slide source was changed for this research.
